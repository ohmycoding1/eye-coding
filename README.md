# 👁 눈으로 코딩

시선 추적(웹캠)·눈 감기·음성으로 조작하는 한국어 블록 코딩 도구입니다. 파일 하나(`index.html`)로 동작합니다.

## 여는 방법
시선 추적은 **https 주소나 localhost**에서만 동작합니다. 파일을 더블클릭해서 열면(`file://`) 마우스·음성 모드로만 쓸 수 있어요.

- **GitHub Pages (추천)**: 저장소 Settings → Pages → Branch를 `main` / `(root)`로 저장하면 `https://<아이디>.github.io/eye-coding/` 주소로 열 수 있어요.
- **내 컴퓨터에서**: 이 폴더에서 `python -m http.server 8000` 실행 후 Chrome에서 `http://localhost:8000` 접속.

## 조작
**👃 코 추적** — 코끝으로 가리켜 커서를 움직이고, **눈을 0.4~2초 감았다 떠서** 선택해요.
- **👃 코 추적 시작** → 노란 점 5개를 차례로 **코끝으로 가리키기**(사람마다 다른 움직임 범위를 화면에 맞춤, "정밀 보정"은 9개) → 눈을 감았다가 삐 소리가 나면 뜨기. 화면을 누르거나 Esc로 건너뛸 수 있어요.
- 🐢 코 속도로 안정/보통/빠름을 고를 수 있어요. 어긋나면 🎯 보정을 다시 누르세요.

**🧲 자석 커서** — 커서가 가까운(80px 안) 버튼·칸에 달라붙어 조금 빗나가도 고를 수 있어요. 버튼이나 "자석 꺼/켜"로 바꿔요.

- **선택**: 눈 감기 / 머무르기 선택을 켜고 1.5초 머무르기 / 스페이스바 / 마우스 클릭.
- **🖼 이미지 오브젝트**: 이미지 올리기 버튼, 무대에 끌어다 놓기, 붙여넣기(Ctrl+V), 또는 "이미지 올리기"라고 말하기. GIF는 움직임 그대로, 큰 사진은 512px로 줄여요.
- **음성**(Chrome): 블록 이름을 말하면 추가되고("10번 반복하기", "와이 좌표를 마이너스 5만큼 바꾸기"), 빨간 칸을 선택한 뒤 말하면 그 칸에 입력됩니다. "실행", "정지", "되돌리기", "밖으로", "모두 지우기", "보정", "이미지 올리기" 명령도 있어요.
