# 👁 눈으로 코딩

시선 추적(웹캠)·눈 감기·음성으로 조작하는 한국어 블록 코딩 도구입니다. 파일 하나(`index.html`)로 동작합니다.

## 여는 방법
시선 추적은 **https 주소나 localhost**에서만 동작합니다. 파일을 더블클릭해서 열면(`file://`) 마우스·음성 모드로만 쓸 수 있어요.

- **GitHub Pages (추천)**: 저장소 Settings → Pages → Branch를 `main` / `(root)`로 저장하면 `https://<아이디>.github.io/eye-coding/` 주소로 열 수 있어요.
- **내 컴퓨터에서**: 이 폴더에서 `python -m http.server 8000` 실행 후 Chrome에서 `http://localhost:8000` 접속.

## 조작
**👃 코 모드 (기본)** — 고개를 돌려 커서를 움직이고, **고개를 끄덕여** 선택해요. 눈동자 시선보다 훨씬 안정적이에요.
- **👃 코 추적 시작** → 얼굴을 네모 안에 맞추고 → 가운데 점을 보며 고개를 편하게 → 안내에 따라 한 번 끄덕이기(끄덕임 감도 측정). 약 5초.
- 끄덕임은 0.9초 안에 빠르게 숙였다 드는 동작이에요. 천천히 아래를 보는 것은 선택되지 않아요. 클릭은 끄덕이기 직전에 커서가 있던 곳을 눌러요.
- 커서가 한쪽으로 치우치면 "가운데"라고 말하거나 🎯 보정을 누르세요. 🐢 커서 속도로 움직임 크기를 바꿀 수 있어요.

**👁 눈 모드** — `👃 코 모드` 버튼(또는 "눈 모드로 바꿔")으로 바꿔요. 시선으로 움직이고 눈을 0.4~2초 감아 선택해요.
- 보정: 얼굴 맞추기 → 노란 점 5개(“정밀 보정”은 9개) → 눈 감았다 뜨기 → 파란 점으로 정확도 확인. 화면을 누르거나 Esc로 건너뛸 수 있어요.

**🧲 자석 커서** — 커서가 가까운(80px 안) 버튼·칸에 달라붙어 조금 빗나가도 고를 수 있어요. 버튼이나 "자석 꺼/켜"로 바꿔요.

- **선택(공통)**: 끄덕임(코 모드)·눈 감기(눈 모드) / 응시 선택을 켜고 1.5초 바라보기 / 스페이스바 / 마우스 클릭.
- **음성**(Chrome): 블록 이름을 말하면 추가되고("10번 반복하기", "와이 좌표를 마이너스 5만큼 바꾸기"), 빨간 칸을 선택한 뒤 말하면 그 칸에 입력됩니다. "실행", "정지", "밖으로", "모두 지우기", "입력" 명령도 있어요.
